# Two-Stage Desalting Process Analysis

An engineering portfolio project based on my work investigating a salt balance discrepancy in a two-stage crude oil desalting process.

The project will present the process through an interactive 3D visualization, alongside explanations of the investigation, experimental work, data analysis, and findings.

## Project Objectives

- Illustrate the equipment, process streams and water circulation.
- Evaluate the desalting process, including alternative demulsifiers and flocculants.
- Present my contribution, findings, and engineering recommendations.

## Project Status

Under development. An initial schematic 3D visualization has been prepared.
